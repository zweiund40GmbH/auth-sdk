# Sicherheitslücken melden

Bitte **nicht** als öffentliches Issue. Stattdessen vertraulich über GitHub melden:
Tab **Security → Report a vulnerability** in diesem Repository.

Hilfreich sind: betroffenes SDK und Version, Beschreibung, Schritte zum Nachstellen und die mögliche Auswirkung.
Wir bestätigen den Eingang und melden uns mit einer Einschätzung. Unterstützt wird jeweils die neueste
Minor-Version jedes SDK.
